# 목소리 맞히기 · 스트리머 편

치지직 스트리머 목소리 몇 초만 듣고 누군지 맞히는 실시간 퀴즈. 방장이 방을 만들고 4자리 코드를 공유하면 친구들이 각자 폰/PC로 접속해서 같이 풀어요 (서버 없이 PeerJS로 연결).

## 하는 법
1. 방장: 사이트 오른쪽 위 **🎙 클립 관리**에서 스트리머 추가 → 방 만들기
2. 친구들: 방 코드(또는 초대 링크)로 참가
3. 방장이 문제 수 · 듣는 시간 · 주관식/객관식 · 제한 시간 고르고 시작

## 클립 추가 형식
한 줄에 한 명:

```
이름 | 별칭1, 별칭2 | 유튜브링크 유튜브링크 ...
```

- `?t=95` 같은 시간이 붙은 링크 → 그 지점부터 재생
- 시간 없는 영상 링크 → 영상 안 랜덤 구간
- 재생목록 링크 (`playlist?list=...`) → 목록 속 영상 중 랜덤 + 랜덤 구간
- 별칭은 정답으로 같이 인정할 이름 (생략 가능)

사이트에서 추가한 건 그 브라우저에만 저장돼요. 다른 PC에서도 쓰려면 **clips.json 내보내기** 후 이 레포의 `clips.json`을 그 파일로 바꿔 올리세요.

## 팁
- 소리가 안 나면 화면의 🔊 버튼을 한 번 누르면 돼요 (브라우저 자동재생 제한).
- 다른 사이트 재생이 막힌 영상은 자동으로 다른 클립으로 넘어가요.
- 방장 버튼: 다시 듣기 / 더 길게 / 다른 구간 / 정답 공개
